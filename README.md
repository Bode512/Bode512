## Selected Projects

### 01. Scanner.cpp

<a href="https://github.com/Bode512/Scanner-cpp">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Bode512&repo=Scanner-cpp&theme=transparent&hide_border=true&title_color=58A6FF&icon_color=58A6FF" width="100%" alt="Scanner.cpp repository card"/>
</a>

A C++20 filesystem-scanning library and command-line tool for inspecting directory trees and reporting file and directory sizes.

**Implemented capabilities documented in the repository:**

- Concurrent filesystem traversal.
- Logical file-size and allocated disk-space reporting.
- Hard-link deduplication.
- Streaming output through result sinks, including CSV.
- Progress reporting and cooperative cancellation.
- Configurable filters and directory traversal.
- CMake build configuration, tests, and benchmarks.

<text>**Technology:** C++20, CMake, CTest</text>

<a href="https://github.com/Bode512/Scanner-cpp">Source code</a> · <a href="https://github.com/Bode512/Scanner-cpp/tree/main/docs">Documentation</a> · <a href="https://github.com/Bode512/Scanner-cpp/blob/main/ROADMAP.md">Roadmap</a>

### 02. Streamline-go

<a href="https://github.com/Bode512/Streamline-go">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Bode512&repo=Streamline-go&theme=transparent&hide_border=true&title_color=58A6FF&icon_color=58A6FF" width="100%" alt="Streamline-go repository card"/>
</a>

A local video-processing server that receives videos from devices, processes them with HandBrakeCLI, and makes the converted files available through a web interface.

**Implemented capabilities documented in the repository:**

- Resumable chunk-based video uploads.
- A processing queue for conversion jobs.
- H.265 video compression using HandBrakeCLI.
- A web dashboard with processing history, statistics, and device information.
- Persistent history using SQLite.
- HTTP endpoints for upload progress, downloads, job control, and status.
- A desktop application component built with Wails.
- Local network discovery and QR-code sharing.

<text>**Technology:** Go, HandBrakeCLI, SQLite, HTTP APIs, Wails</text>

<a href="https://github.com/Bode512/Streamline-go">Source code</a> · <a href="https://github.com/Bode512/Streamline-go/blob/main/README.md">Documentation</a>

<sub>Security note: the project documentation states that the local server has no authentication or authorization. It should not be exposed directly to the public internet.</sub>
